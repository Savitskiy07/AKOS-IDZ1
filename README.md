# Картинная галерея

## Отчёт по индивидуальному заданию

**Вариант:** 16

**ФИО исполнителя:** Савицкий Александр

**Группа:** 252

## 1. Условие задачи

Галерея имеет ограничение на общее число посетителей. Возле каждой картины одновременно находится не более заданного числа людей. Посетители прибывают через случайные интервалы, ждут разрешения вахтёра, осматривают все картины и выходят.

Посетитель выбирает картины случайно или по порядку. Если у выбранной картины нет места, он ждёт в очереди. Программа отображает прибытие, ожидание у входа, разрешение, вход, выбор картины, ожидание места, начало и окончание осмотра и выход.

## 2. Представление задачи в программе

| Сущность | Представление | Действие |
| --- | --- | --- |
| Вахтёр | FIFO-очередь входа | Разрешает вход при свободном месте |
| Посетитель | `Visitor` | Хранит маршрут и осматривает все картины |
| Картина | `Painting` и FIFO-очередь | Ограничивает число зрителей |
| Рабочий день | `Gallery` | Хранит состояние и статистику |

Реализация последовательная: все действия выполняются одним циклом событий. Активные осмотры имеют виртуальное время окончания, поэтому несколько осмотров могут перекрываться в модели без потоков ОС.

Главные инварианты: вместимость галереи и каждой картины не превышается; посетитель находится не более чем у одной картины; картина засчитывается не более одного раза; вышедший посетитель освобождает место.

## 3. Интерфейс и завершение

Параметры можно задать аргументами командной строки, конфигурационным файлом `key=value` или интерактивно. Поддерживаются вместимость, число картин, число посетителей, интервалы прибытия, длительность осмотра, стратегия и seed.

```bash
cmake -S . -B build-cmake
cmake --build build-cmake
./build-cmake/gallery --config examples/demo.conf
```

Нормальное завершение происходит после обработки всех прибытий и выхода посетителей. При SIGINT или SIGTERM новые прибытия прекращаются, очереди очищаются, активные осмотры прерываются, после чего освобождаются все места.
